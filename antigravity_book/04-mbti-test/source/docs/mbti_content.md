# 개발자 성향 MBTI 테스트 기획서

## 1. 개요
개발자들의 코딩 스타일, 협업 방식, 선호하는 도구 등을 기반으로 재미있는 '개발자 성향'을 도출하는 웹 콘텐츠입니다.

## 2. User Flow (화면 흐름)
1.  **시작 화면 (Intro)**
    *   타이틀: "나는 어떤 개발자일까?"
    *   서브 타이틀: "재미로 알아보는 개발자 성향 테스트"
    *   '시작하기' 버튼
    *   참여자 수 카운터 (선택 사항)
2.  **질문 화면 (Question)**
    *   총 12개 내외의 문항 진행
    *   상단 프로세스 바 (진행률 표시)
    *   질문 텍스트 + 애니메이션/이미지
    *   2개의 답변 버튼 (A vs B)
3.  **로딩 화면 (Loading)**
    *   "코드를 컴파일 중입니다..." 등의 문구
    *   분석 중임을 나타내는 로딩 애니메이션
4.  **결과 화면 (Result)**
    *   나의 개발자 유형 (타이틀 + 이미지)
    *   유형 설명 및 특징 (장점, 단점)
    *   잘 맞는 유형 / 안 맞는 유형 궁합
    *   '다시 하기' 버튼
    *   '공유하기' 버튼

## 3. 개발자 유형 (8가지)
재미를 위해 다소 과장된 특징을 잡았습니다.

1.  **픽셀 깎는 장인 (프론트엔드형)**: 1px의 오차도 용납하지 않으며, UX/UI에 집착합니다. "이거 버튼 색깔이 미묘하게 다른데요?"
2.  **논리적인 설계자 (백엔드형)**: 보이지 않는 데이터의 흐름과 아키텍처를 중요시합니다. "화면은 중요하지 않아, 데이터가 정확하면 돼."
3.  **혼돈의 마법사 (스파게티형)**: 일단 돌아가게 만드는 것이 목표. 나만 알아볼 수 있는 코드를 짭니다. "작동하는데 왜 건드려?"
4.  **만능 해결사 (풀스택형)**: 서버도 알고 클라이언트도 압니다. 하지만 가끔 정체성의 혼란을 겪습니다. "제가 다 할게요."
5.  **효율성 덕후 (데옵스형)**: 반복 작업을 혐오합니다. 모든 것을 자동화하려고 스크립트를 짭니다. "이거 3번 이상 반복되면 자동화하죠."
6.  **오픈소스 전도사 (커뮤니티형)**: 공유와 협업을 즐깁니다. 깃헙 잔디 심기가 취미입니다. "PR 보냈습니다 확인해주세요."
7.  **기술 힙스터 (얼리어답터형)**: 최신 기술은 다 써봐야 직성이 풀립니다. 안정성보다는 신기술 도입이 먼저입니다. "이번에 나온 프레임워크 써보셨어요?"
8.  **돌다리 두드리는 선비 (안정지향형)**: 레거시를 존중하고 변화를 두려워합니다. 검증된 기술만 사용합니다. "그거 도입했다가 터지면 책임 지실 건가요?"
