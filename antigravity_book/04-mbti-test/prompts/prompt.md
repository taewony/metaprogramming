# 7장: 나만의 개발자 성향 테스트 만들기
- 기획자 에이전트 (콘텐츠 기획):
    - "제목 개발자 성향 MBTI 테스트 웹 앱 구축 너는 IT 트렌드에 민감한 바이럴 콘텐츠 전문 기획자야.
    - 주제: 개발자들이 공감할 수 있는 개발자 성향 테스트(MBTI)의 문항과 결과 데이터를 기획해 줘. 개발자 성향 테스트 (예: 프런트엔드형, 백엔드형, 스파게티 코드형 등 재미있는 유형 도출, 최소 6가지 이상의 결과 포함)
    - 질문과 결과 유형을 포함한 콘텐츠 데이터를 JSON 형태로 구조화해 줘.
    - 모든 콘텐츠는 한글로 작성해 줘.
    - 기획과 콘텐츠만 작성해서 MD 파일로 만들어 줘. 파일 이름은 ‘mbti_content’로 하고 root 폴더에 파일을 생성해 줘.
    - "너는 100만 유저를 보유한 바이럴 마케팅 서비스의 수석 PM이야. 개발자들이 공감할 수 있는 'B급 감성'과 '전문성'을 섞어서 콘텐츠를 기획해 줘. 너무 진지한 성격 검사가 아니라, "금요일 오후 배포 가능?" 같은개발자 밈과 유머를 섞어야 해. 타깃 유저는 2030 개발자야." (페르소나 강화)

- 화면 설계 및 시각화:
    - "화면 흐름을 설계해 줘. (시작-질문-로딩-결과)... 닉네임 입력과 결과 이미지 저장 아이디어 반영해서 수정해 줘."
    - "작성해 준 User Flow를 한눈에 볼 수 있게 Mermaid Flowchart 코드로 작성해서 기획서에 추가해 줘."

- 디자인 시스템 구축:
    - "너는 프런트엔드 개발 역량을 갖준 UI/UX 디자인 전문가야. 아래 URL을 참조해서 우리 프로젝트(개발자 성향 테스트)에 필요한 Shadcn/ui 사용 가이드 문서를 만들어 줘.
    **참조 URL:** https://ui.shadcn.com/docs/components 
    **[요청 사항]**
    1. **설치 방법:** Next.js 환경에서 Shadcn/ui를 초기 설정(init)하는 CLI 명령어
    2. **필수 컴포넌트 사용법:** 아래 컴포넌트들의 '설치 명령어(CLI)'와 '기본 사용 예제 코드'를 정리해줘.
    - Button (버튼)
    - Card (질문과 결과를 보여 줄 카드)
    - Progress (진행률 표시 바)
    - Radio Group (답변 선택지)
    3. **출력:** 위 내용을 마크다운 형식으로 작성해서 루트 경로에 `shadcn_guide.md` 파일로 생성해 줘."
