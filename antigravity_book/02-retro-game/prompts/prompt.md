# 4장: 안티그래비티로 레트로 게임 만들기
- 기획자 에이전트 (게임 아이디어 제안): "너는 10년 차 레트로 아케이드 게임 기획자야. 파이썬(Python)의 pygame 라이브러리를 이용해서 만들수 있는 ‘레트로 스타일의 우주 슈팅 게임’ 아이디어를 4가지 추천해 줘. 조건이 있어.
첫째. 4가지 게임 스타일의 이름과 핵심 플레이 방식을 명확히 구분해서 설명할 것.
둘째. 각 스타일마다 개발 관점에서의 특장점(구현 난이도, 시각적 재미 요소 등)을 반드시 포함할 것.
셋째. 초보 관리자가 직관적으로 선택할 수 있도록 쉬운 용어를 사용할 것.
이 조건을 이용해서 ‘레트로 게임 스타일의 우주 슈팅 게임’을 만들고 싶은데 좋은 아이디어를 추천해 줘.
4가지 정도 추천해 주고 각 스타일마다 게임의 특장점을 알려 줘."

- MVP 기획서 생성: "3번 고정 화면 웨이브 디펜스가 좋을 것 같아. 이 내용을 바탕으로 간단한 MVP 모델의 기획서를 작성해 줘. 워크스페이스 폴더 안에 mvp_plan.md라는 마크다운 파일을 직접 생성해서 저장해 줘."

- 개발자 에이전트 (MVP 개발): "너는 코딩 초보자를 돕는 친절한 파이썬 게임 개발 멘토야. 워크스페이스에 있는 mvp_plan.md 파일을 이
용해서 게임을 만들어 줘. 내가 파이썬에 익숙하지 않으니 코드를 작성할 때 다음 규칙을 지켜줘.
[규칙]
1. 모든 주석과 콘텐츠는 한글로 작성해 줘.
2. 코드를 제시하기 전에 어떤 구조로 파일을 나누어 개발할 것인지 먼저 간단히 설명해 줘 ."

- 디버깅 및 로직 수정:
    - "이런 에러가 발생하는데 해결해줘." (에러 로그 첨부)
    - "이 코드에서 적이 움직이는 로직이 어디야?"
    - "ENEMY_SPEED_X값을 변경하면 적의 움직임 속도가 변경되겠네?"

- 디자이너 에이전트 (에셋 생성):
    - "너는 최고 수준의 AI 프롬프트 엔지니어... 내 게임의 그래픽과 UI를 전담할 디자이너 에이전트에게 부여할 상세한 시스템 프롬프트를 작성해 줘..."
    - "mvp_plan.md 이 기획서를 바탕으로 게임 인트로 화면 이미지를 만들어 줘."
    - "Player Ship, Enemy Ship, Background 이 세 개의 이미지를 각각 생성해 줘."
    - "assets 폴더에 있는 이미지를 player/enemy/background 폴더로 나눠 줘."

- 그래픽 적용 및 최종 폴리싱:
    - "assets 폴더에 있는 이미지 파일을 이용해서 기존의 게임의 이미지를 변경해 줘.
    intro_screen 파일은 처음 게임을 시작했을 때 배경 화면으로 사용해 줘.
    space_background 파일은 본격적으로 게임을 할 때 배경 화면에 사용해 줘.
    enemy 폴더에 있는 파일은 데이터는 적과 적이 발사하는 미사일에 사용해 줘.
    player 폴더에 있는 파일은 플레이어와 플레이어가 발사하는 미사일에 사용해 줘.
    explosion_fx 파일은 적이 미사일에 맞았을 때 사용해 줘."

    - "게임이 종료되었을 때 R 버튼을 누르면 다시 실행되도록 만들어 줘."
    
    - "이 이미지의 배경 화면을 흰색으로 바꿔줘." (제미나이 웹 활용)
    
    - "게임 실행 시 player_ship.png와 적군(enemy) 이미지 주변에 흰색 배경이 나타나. 해당 흰색 영역이 게임 플레이 중 완전히 투명하게 보이도록 처리해 줘."

- 시스템 확장 및 배포:

    - "게임이 완성되어서 이제 이 게임을 배포할 수 있도록 exe 파일로 만들어 줘."
