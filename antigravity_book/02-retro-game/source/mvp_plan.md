# 우주 방어 게임 (Space Defender) MVP 기획서

## 1. 게임 개요
- **장르**: 고정 화면 웨이브 디펜스 슈팅 (갤러그 스타일)
- **목표**: 플레이어는 우주선을 조종하여 화면 상단에서 대형을 이루며 다가오는 외계 적들을 모두 물리쳐야 합니다.
- **플랫폼**: PC (Windows)
- **개발 도구**: Python 3.x, Pygame 라이브러리

## 2. MVP 핵심 기능 (최소 기능 제품)
이 단계에서는 화려한 그래픽보다 **핵심 플레이 루프**의 동작에 집중합니다.

### 2.1 플레이어 (Player)
- **이동**: 좌/우 화살표 키로 이동 (화면 밖으로 나가지 못하게 제한)
- **공격**: 스페이스바를 눌러 미사일 발사 (연사 속도 제한: 0.5초 쿨타임)
- **생명**: 적이나 적의 미사일에 닿으면 게임 오버 (MVP에서는 목숨 1개)

### 2.2 적 (Enemy)
- **출현**: 게임 시작 시 3행 8열(예시)의 그리드 형태로 배치
- **이동**:
    - 전체 적 그룹이 좌우로 이동
    - 화면 끝에 닿으면 아래로 한 칸 내려오고 이동 방향 반전
- **공격**: 일정 확률로 무작위 적이 아래로 미사일 발사
- **피격**: 플레이어의 미사일에 맞으면 소멸

### 2.3 게임 시스템 (System)
- **충돌 처리**:
    - 플레이어 미사일 <-> 적 (적 소멸, 점수 획득)
    - 적 미사일 <-> 플레이어 (게임 오버)
    - 적 <-> 플레이어 (게임 오버)
- **승리 조건**: 화면의 모든 적을 제거하면 "YOU WIN" 출력 후 종료
- **패배 조건**: 플레이어가 파괴되거나, 적이 플레이어 위치(화면 최하단)까지 내려오면 "GAME OVER"

## 3. UI / 그래픽 (MVP 기준)
- **그래픽**: 복잡한 스프라이트 대신 컬러 **사각형(Rect)**으로 대체하여 로직 구현 우선
    - 플레이어: 초록색 사각형
    - 적: 빨간색 사각형
    - 미사일: 흰색/노란색 작은 사각형
- **텍스트 UI**:
    - 화면 좌측 상단: Score (현재 점수)
    - 게임 종료 시: 중앙에 큰 글씨로 결과 표시

## 4. 추후 확장 가능성 (Post-MVP)
- 적의 다양한 비행 패턴 (곡선 이동 등)
- 보스전 추가
- 아이템 시스템 (파워업, 쉴드)
- 사운드 효과 및 배경음악
- 고퀄리티 이미지 리소스 적용
