# 파일 시스템 자동화 스크립트 기획서

특정 폴더에 있는 파일들을 확장자 기준의 명확한 카테고리(이미지, 문서, 영상 등)로 자동 분류하여 정리하는 파이썬 스크립트 작성에 대한 기획서입니다.

## Proposed Changes

### File Organization Script
파이썬 초보자도 쉽게 실행할 수 있도록 외부 라이브러리(pip 설치 등) 없이 기본 제공 라이브러리(`os`, `shutil`, `pathlib`, `tkinter`)만 사용하여 단일 파일로 작성합니다.

#### [NEW] [organize.py](file:///c:/Users/ikiny/OneDrive/Documents/antigravity/py_folder/organize.py)
* **GUI 폴더 선택기 (`tkinter.filedialog`)**: 스크립트 실행 시 직관적인 폴더 선택 창(UI)을 띄워 사용자가 정리할 대상 타겟 폴더를 직접 선택하도록 구현.
* **지정되지 않은 확장자 처리**: 매핑 규칙에 명시되지 않은 확장자(예: .zip, .exe 등)는 이동시키지 않고 **원래 폴더에 그대로 보존**합니다.
* **폴더 매핑 딕셔너리**: `{'이미지': ['.jpg', '.png'], '문서': ['.pdf', '.docx', '.xlsx', '.txt'], '영상': ['.mp4']}` 
* **중복 처리 함수 (`get_unique_path`)**: 대상 폴더에 중복 이름이 있을 경우 `파일명(1).확장자`, `파일명(2).확장자` 순으로 이름 충돌을 회피하는 로직 적용
* **파일 이동 로직 (`organize_files`)**: 대상 폴더를 스캔한 후 조건에 맞는 각각의 폴더를 생성하고 안전하게 파일 이동 수행. *(단, 다운로드 폴더 내의 '프로젝트 폴더' 등 모든 디렉터리는 이동 대상에서 제외하고 안전하게 보존합니다.)*
