# 파일 정리 스크립트 완성

요청하신 `organize.py` 스크립트 파일의 작성을 완료했습니다!

## 구현된 기능
1. **Tkinter UI 폴더 선택기**: 스크립트를 실행하면 깔끔한 폴더 선택 창이 나타나 정리하고 싶은 폴더를 쉽게 고를 수 있습니다. (초보자 친화적)
2. **확장자 자동 분류**: 지정한 폴더 안의 파일들을 `이미지`, `문서`, `영상` 폴더로 자동 생성 후 쏙쏙 옮겨줍니다.
3. **다운로드 내 프로젝트 보호**: 폴더(디렉터리) 자체는 이동시키지 않고 보호되도록 처리되었습니다.
4. **안전한 이름 중복 방지**: 이미 같은 이름의 파일이 있을 경우 `파일명(1).확장자`, `파일명(2).확장자` 순으로 똑똑하게 이름을 바꿔서 이동시킵니다.
5. **기타 파일 보존**: `.zip` 등 규칙에 없는 파일들은 원본 위치에 그대로 남습니다.
6. **단일 파일 & 무설치**: 추가 설치(pip) 없이 파이썬 기본 기능만으로 작동하도록 만들었습니다.

## 실행 방법 (검증 요청)
현재 환경에서 자동 테스트가 파이썬 경로 문제로 제한되어, 직접 실행해보시기를 권장합니다.

1. 파일 탐색기나 IDE(예: VSCode)에서 `organize.py`가 있는 폴더(`C:\Users\ikiny\OneDrive\Documents\antigravity\py_folder`)로 이동합니다.
2. `organize.py` 스크립트를 실행합니다.
   * VS Code 사용 중이라면 우측 상단의 `▶` (Run) 버튼을 누릅니다.
   * 또는 터미널에서 `python organize.py` 를 입력합니다.
3. 나타나는 창에서 정리할 임의의 더미 폴더(혹은 다운로드 폴더)를 선택하여 올바르게 분류되는지 확인해주세요.

혹시 수정이 필요한 부분이나 추가하고 싶은 기능이 있다면 언제든 알려주세요! 😊
