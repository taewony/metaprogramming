# 5장: 안티그래비티로 생산성 도구 만들기
- 폴더 정리 자동화 스크립트 기획: "[R] 너는 파이썬(Python) 기반의 파일 시스템 자동화 스크립트를 작성하는 수석 엔지니어이자 내 개인 비서야.
[O] 특정 폴더(예: 다운로드 폴더)에 있는 파일들을 확장자에 따라 자동으로 분류해서 하위 폴더로 이동시키는 파이썬 코드를 작성해 줘. 내 다운로드 폴더가 너무 지저분해서 정리해야겠어.
[C] 나는 파이썬 초보자라서 실행하기 쉬운 형태의 단일 파일(organize.py)이었으면 좋겠어.
[K] 폴더 생성 규칙: 이미지(jpg, png), 문서(pdf, docx, xlsx, txt), 영상(mp4) 등 확장자별로 폴더를 자동 으로 생성해 줘.
중복 처리: 옮기려는 폴더에 이름이 같은 파일이 이미 있다면 덮어쓰지 말고 파일명 뒤에 숫자를 붙여서(예 : file(1).txt) 이동시켜 줘."

- 기능 고도화:
    - "UI를 구현해서 폴더를 선택할 수 있도록 만들어 줘. 관련된 라이브러리도 추가해서 기획서를 다시 작성해 줘."
    - "최종으로 수정한 날짜가 1년이 지난 파일은 'oldfiles' 폴더로 이동할 수 있도록 만들어 줘."
    - "해당 코드를 실행할 때 로그를 남길 수 있게 만들어 줘. logs 폴더를 생성해서 로직을 실행한 날짜와 파일을 어디로 옮겼는지 로그를 작성해서 "YYYYMMDD_HH:mm:SS_summary.txt" 파일로 만들어 줘."
    - "이프로그램을 exe 파일로 만들어줘."
    - 제미나이 API 연동 (스마트 분류): "특정 폴더 내의 파일들을 분석하여 “업무”와 “개인” 폴더로 자동 분류하여 이동시키는 Python 프로그램을작성해줘.
    핵심 요구사항
    1. gemini API를 사용해줘 Google Gemini API (model: ‘gemini-flash-lite-latest’)를 사용해줘. api 키는 “API 키”야
    2. 비용과 속도를 위해 한 번의 API 호출에 파일 10개씩 묶어서 처리해줘.
    3. 파일 전체를 읽지 않고, 각 파일의 앞부분(약 1,000자 내외)만 추출하여 분석에 사용해줘"
