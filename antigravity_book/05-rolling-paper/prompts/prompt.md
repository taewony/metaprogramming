# 8장: 디지털 롤링페이퍼 서비스 구현
- 백엔드 설계 (Supabase):
    - "[R] 너는 수파베이스와 데이터베이스 설계에 정통한 10년 차 시니어 백엔드 개발자야.
    [O] 우리가 새로 만들 “디지털 롤링페이퍼” 서비스의 데이터베이스 테이블 구조와 컬럼을 설계해 줘.
    [C] 수파베이스를 이용해서 서버 없이 백엔드를 구축하려고 해. 사용자가 보드(롤링페이퍼 방)를 만들면,방문자들이 그 보드에 여러 개의 메시지(포스트잇)를 남기는 구조야.
    [K] 다음 조건을 지켜서 설계해 줘.각 테이블에 필요한 필수 컬럼(id, 생성일 등)과 두 테이블 간의 관계를 명확히 포함해서 한눈에 보기 쉬운 표 형태로 정리해 줘."
    - "해당 설계도에 맞춘 SQL 쿼리를 작성해줘."

- DB 연동 및 보안 정책:
    - "이제 이 테이블에 데이터를 넣어 테스트해 보고 싶어. 간단한 페이지를 만들고 데이터베이스에 입력되도록 만들어 줘."
    - "앱의 boards 테이블에 대한 Row Level Security(RLS) 정책을 추가해 줘.
    방금 카카오 로그인을 구현했어. 로그인한 사용자(authenticated role)는 누구나 자유롭게 방(boards)을만들 수 있어야 해.
    boards 테이블에 INSERT 정책을 추가하는 SQL을 작성해 줘. 로그인한 사람이면 Insert를 할 수 있도록 만들어 줘.
    추가로 owner_id 컬럼이 실제 로그인한 유저의 ID와 일치하는지도 체크해 주면 더 좋을 것 같아"

- 핵심 기능 명세 및 개발:
    - "너는 UX/UI 기획자이자 프런트엔드 개발자 에이전트야, 디지털 롤링페이퍼 서비스의 핵심 기능인 보드 및 포스트잇 상호작용에 대한 기능 명세서를 작성해 줘."
    - "[R]너는 보안 시스템 엔지니어이야. [O]우리 프로젝트에 Supabase Auth(로그인) 기능을 연동하기 위한 초기 설정과 코드를 작성해 줘."

- 인터랙션 및 실시간 기능:
    - "포스트잇을 옮기는 기능을 추가해 줘. 내가 작성한 포스트잇만 옮길 수 있도록 만들고, 롱클릭으로 포스트잇을 잡고 옮기면 해당 위치로 포스트잇이 이동하도록 해줘. 이동이 완료되면 해당 포스트잇의 위치 좌표를 수정해서 데이터베이스에 저장되도록 만들어 줘."
    - "데이터베이스가 추가되거나 변경되면 다른 웹 화면에서도 DB가 자동으로 업데이트될 수있도록 Subscribe Realtime 기능을 추가해 줘."

- 모바일 앱 확장 및 배포:
    - "너는 React Native(Expo) 앱 개발 전문가야.내 웹 서비스(https://rolling-paper-chi.vercel.app/#)를 감싸서 보여 주는 웹뷰(WebView) 기반의 모바일 앱을 만들어 줘.
    React Native와 Expo 프레임워크를 사용해. 앱이 실행되면 바로 웹 사이트가 전체 화면으로 떠야 해. 노치 디자인을 고려해 줘.
    안드로이드 뒤로 가기 버튼을 눌렀을 때, 앱이 꺼지지 않고 웹 사이트 내에서 뒤로 이동하게 처리해 줘. 웹 페이지가 로딩되는 동안에는 로딩바가 중앙에서 돌게 해줘. 앱에 필요한 권한 설정도 해줘.
    요청 사항: 모든 기획서와 문서, 주석은 한글로 작성해 줘."
