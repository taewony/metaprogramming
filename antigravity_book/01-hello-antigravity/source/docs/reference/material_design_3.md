# Material Design 3 Reference

**Source:** [Get started with Modern UI design - Material Design 3](https://m3.material.io/get-started)

## Overview
Material Design 3 (M3) is an adaptable system of guidelines, components, and tools that support the best practices of user interface design. It streamlines collaboration between designers and developers to build beautiful products.

## key Sections

### What's Material?
Learn how Material enables beautiful product design at Google scale. It provides the foundational guidance for creating user experiences.

### What's Material 3 Expressive?
Explore new features, components, and tactics for emotionally impactful UX. This likely covers the more vibrant and personalized aspects of M3.

### Using Material
Resources to get to know Material.io and top resources for using the system.

### Design
Guidance on applying:
- **Color**: Dynamic color systems.
- **Type**: Typography scales and usage.
- **Adaptive Design**: Patterns for different screen sizes and devices.

### Develop
Developer resources and code are available for:
- **Android**: Jetpack Compose and View-based UI.
- **Flutter**: Cross-platform support.
- **Web**: Web Components and tutorials (in development for M3).
