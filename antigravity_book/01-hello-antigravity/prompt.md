- 에이전트 역할 및 능력 확인: "너는 어떤 AI 모델이고, 내가 무엇을 할 수 있도록 도와줄 수 있어?"

- 기초 파일 생성 실습: "현재 폴더에 hello.py 파일을 만들고 'Hello Antigravity!'를 출력하는 코드를 작성해 줘."
- 바이브 코딩 (타이머 프로그램 기획): "웹으로 구현한 간단한 타이머를 만들어 줘, 바로 코드를 작성하지 말고, 먼저 전체 구현 순서와 파일별 핵심 로직을 정리한 Implementation_Plan.md 파일을 생성해 줘. 내가 그 계획을 확인하고 승인(Review)하면 그때 실제 코딩을 시작해"

- 기능 추가 및 수정: "파스타 타이머 기능을 추가해 줘, 파스타 버튼을 누르면 자동으로 8분 타이머가 시작되게 만들어 줘."
- 인라인 명령어: "@index.html#L42-44 버튼을 영어에서 한글로 변경해줘"

- 이미지/문서 코멘트: "글자색을 녹색 테마로 변경해 줘."

- Fast 모드 활용: "다크 모드 ON/OFF 버튼을 추가해 주고 OFF일 때는 배경을 밝은색으로 변경해 줘."

- 실행: "프로그램을 시작해줘."

# 3장: 안티그래비티에 맥락 전달하기
- @멘션 활용 실습:
    - "@script.js에 한글 주석을 작성해 줘."
    - "@index.html#L22-35 라벨을 한글로 변경해 줘."
    - "@script.js#L39-54 이 코드가 어떻게 동작하는지 초보자도 알기 쉽게 설명해 줘."
    - "@script.js 파일에서 시간 종료하는 로직이 어디 있는지 찾아 줘."
- 구조 및 데이터 참조:
    - "@reference폴더를 참조해서 style.css 디자인에 대한 상세한 설명을 작성해줘."
    - "@PostgresDB.sql를 확인해서 메시지 테이블 스키마에 맞는 쿼리를 짜줘."
    - "@어제_디버깅했던 대화를 요약해서 새로운 대화 창으로 이어갈 수 있게 만들어 줘."
    - "@Terminal 내용을 보고 방금 실행한 코드에 오류가 났는지 확인해줘."
- 규칙(Rules) 설정:
    - "root 폴더에 antigravityrules를 생성해 줘."
    - "@.antigravityrules 이 룰을 기본으로 전체 코드를 수정해줘."
- 공식 문서 참조(RAG):
    - "너는 테크니컬 라이터(Technical Writer)이자 UI 디자이너야. 아래 URL의 내용을 분석하여 개발자가 참고할 수 있는 머터리얼 디자인 가이드 요약 문서를 작성해 줘. (참조 URL: https://m3.material.io/get-started)"
    - "@direcroty reference 폴더에 있는 md 파일을 이용해서 지금 타이머의 디자인을 머터리얼 스타일로 변경해 줘."
- 대화 요약: "지금까지 작업한 내용을 요약해서 다음 대화에서 쓸 수 있게 정리해 줘."
