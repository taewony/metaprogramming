## Summary

This document introduces foundational database concepts and SQL basics for beginners. It explains how data is organized in tables, the role of primary key and foreign key in linking tables, and the meaning of null value in relational databases. The text also includes practice questions to reinforce understanding of these core ideas.

### Key Concepts

- **Database**: A structured system for storing and retrieving data efficiently.  
- **SQL**: A standardized language for managing relational databases, supporting CRUD operations (CREATE, READ, UPDATE, DELETE).  
- **Table**: A collection of related data organized into rows and columns.  
- **Primary Key**: A unique identifier for each row, ensuring data integrity.  
- **Foreign Key**: A field that references another table’s primary key, establishing relationships.  
- **Null Value**: Represents the absence of a value, distinct from zero or an empty string.  

### Findings

- Normalization reduces redundancy and improves data consistency across tables.  
- SQL enables efficient querying and manipulation of data in relational systems.  
- Relationships between tables are enforced through primary key and foreign key constraints.  

### Ideas

- Understanding these concepts is essential for working with relational databases.  
- Practicing SQL queries helps users gain hands-on experience with data management.
