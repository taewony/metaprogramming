brief: "NULL represents the absence of a value in a database field."
---

The NULL value in a database indicates that a field contains no data. It is distinct from zero or an empty string. In the context of the [[summaries/00-introduction]] document, NULL is used to represent missing or undefined information, such as a customer's birth date that has not been entered. NULL is a fundamental concept in relational databases and is often discussed in the context of data integrity and query operations. For more details on NULL, see the [[concepts/null_value]] page.
