# AI based Data Query and response Engine

## 개발방향(PRD.md)을 확정하기 위한 질문 list

1. 최종 목표·결과물 관련 질문
- 사용자는 음성으로만 질문하는 구조인지, 음성+텍스트 입력을 모두 지원해야 하는지 궁금합니다.
- 최종 응답은 단순 텍스트 답변인지, 표/그래프/요약/근거 문서까지 포함해야 하는지 궁금합니다.

2. 사용자 발화 데이터 관련 질문
- 실제 사용자가 어떤 형태로 질문할 것으로 예상하는지 예시가 있는지 궁금합니다. 예: “지난달 매출 알려줘”, “이 문서에서 지원 조건 찾아줘”, “OO 사업 신청 대상이 누구야?
- 사용자의 질문이 주로 DB 조회형인지, 문서 검색형인지, 아니면 둘 다 포함하는지 궁금합니다.
- STT 전 음성 데이터와 STT 후 텍스트 데이터 중 어떤 데이터를 제공받을 수 있는지 궁금합니다.
- 개발용 샘플 발화 데이터셋이 이미 구축되어 있는지, 없다면 학생팀이 직접 만들어야 하는지 궁금합니다.

3. STT 연계 관련 질문
- STT 결과가 단순 텍스트인지, confidence score, timestamp, 화자 정보, 후보 문장 n-best까지 포함되는지 궁금합니다.
- STT 결과에 오인식이 포함될 경우, LLM이나 알고리즘으로 후처리/정제하는 단계가 필요한지 궁금합니다.
- STT 모듈은 API 형태로 제공되는지, 파일 입력/출력 방식인지, 별도 서버 연동이 필요한지 궁금합니다.
- STT 결과를 실시간 스트리밍으로 받아야 하는지, 녹음 완료 후 일괄 처리해도 되는지 궁금합니다.

4. 자연어 정제·NLU 관련 질문
- 사용자의 질문이 불명확할 때 바로 SQL을 생성하지 않고 “어떤 기간을 말씀하시는 건가요?”처럼 되묻는 기능이 필요한지 궁금합니다.
- “그럼 지난달은?”, “아까 말한 거 다시 보여줘”처럼 이전 대화를 참조하는 질문도 처리해야 하는지 궁금합니다.

5. Text-to-SQL 개발 관련 질문
- 연동 대상 DB가 PostgreSQL, MySQL, Oracle 등 어떤 DB인지 궁금합니다.
- 테이블명, 컬럼명, 관계, ERD, 샘플 데이터가 제공되는지 궁금합니다.
- SELECT 조회만 허용하는지, INSERT/UPDATE/DELETE 같은 변경 쿼리는 금지하는지 궁금합니다.
- 단순 조회뿐 아니라 집계, 정렬, 그룹화, 기간 비교, 증감률 계산까지 포함해야 하는지 궁금합니다.
- Text-to-SQL 정확도를 어떤 기준으로 평가할지 궁금합니다. 예: 정답 SQL 일치율, 실행 결과 일치율, 사용자 만족도 등

6. RAG·문서 질의 관련 질문
- 사용자의 질문이 DB뿐 아니라 PDF, HWP, Word, Excel 같은 문서 내용 검색도 포함하는지 궁금합니다.

7. 도메인 사전·용어 관련 질문
- 기관명, 사업명, 약어, 고령자 표현, 지역명 등을 정리한 도메인 사전이 이미 있는지 궁금합니다.
- 고령자 발화에서 자주 나오는 사투리나 비표준 표현 사전이 있는지 궁금합니다.
- 사용자가 말하는 자연어 표현과 DB 컬럼명을 연결하는 매핑 사전이 필요한지 궁금합니다.
