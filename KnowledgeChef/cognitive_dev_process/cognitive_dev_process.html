ActiveGraph Text-to-Query Baseline

A learning dashboard for the transition from the frozen Text-to-SQL v11.5 experiment to a clean Text-to-Query architecture prepared for OKF KB and RAG work.

Created: 2026-07-23 Frozen baseline: text-to-sql-agent v11.5 New baseline: text-to-query-agent v00 Mode: cognitive dev-loop

Purpose

This dashboard turns the agent development process into a study artifact. It shows not only what files were created, but why the architectural transition exists and how future work should be evaluated.

The previous Text-to-SQL implementation remains valuable as evidence. The next Text-to-Query line starts from a cleaner system model so OKF KB ingestion and RAG can be added without overloading the experiment folder.

Core principle

Freeze the proven experiment. Start the product-shaped architecture from a declarative system model. Preserve behavior through eval evidence before adding new capability.

Architecture Transition

Frozen Reference

Folder: activegraph/text-to-sql-agent

  • DB-only deterministic baseline
  • Hospital and TechShop packs
  • Third-party pack import prototype
  • Eval-run export and score attachment
  • Reference tests: 63 passed
→

New Baseline

Folder: activegraph/text-to-query-agent

  • System-model-first architecture
  • ActiveGraph imported as runtime library
  • TextToQueryAgent service boundary
  • PackContext resource boundary
  • Prepared for DB, OKF schema, OKF KB, and RAG

Layering Model

ActiveGraph runtime library
  Graph / Event / Runtime / Behavior / EventStore

TextToQueryAgent application layer
  PackContext
  SystemModelLoader
  QueryTarget adapters
  BehaviorFactory
  EvalRun protocol
  CLI / REPL

The new line should import ActiveGraph primitives instead of placing query-specific behavior inside the generic ActiveGraph CLI/runtime layer.

Development Timeline
