# Personal Finance Assistant (Local SLM)

A Python console demo of a Personal Finance Assistant that uses a local language model via Ollama. It showcases five core functions:

1. **Expense Analysis** – Input salary and expenses, then receive total income, total expenses, savings and simple suggestions.
2. **Budget Planning** – Input income and a savings goal, and get a recommended budget allocation.
3. **Investment Advice** – Input a risk level (Low / Medium / High) and receive a beginner‑friendly portfolio suggestion.
4. **Financial Chat (multi‑turn)** – Ask personal‑finance related questions in a conversational style. The chat maintains context for the session; typing an empty line exits the chat.
5. **Goal & GAP Analysis** – Input income, expenses, and a financial goal. The local SLM performs a gap analysis and streams realistic guidance on how to reach the goal.

## How to Run

### Option 1: Double‑click the starter script (Windows)

```text
启动个人财务助手.bat
```

### Option 2: Run from the command line

```bash
python main.py
```

### Option 3: Generate demo output (one‑click)

```bash
python demo_run.py
```
Or double‑click:

```text
一键演示.bat
```
The demo output will be saved to:

```text
outputs/demo_output.txt
```

## Ollama / Local SLM Configuration

The program will first try to use a locally running Ollama server. Install and start Ollama, then pull the desired model:

```bash
ollama pull qwen2.5:7b
ollama serve
python main.py
```
You can switch to any other model supported by Ollama by setting the `OLLAMA_MODEL` environment variable, e.g.:

```bash
set OLLAMA_MODEL=llama3
python main.py
```
Supported example models include:

```text
llama3
gemma3
phi3
qwen2.5:7b
```
If Ollama is not installed or not running, the program falls back to built‑in demo outputs so the project can be displayed without any extra setup.
